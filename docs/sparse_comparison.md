# L1/L2脉冲驱动稀疏设计与当前稠密设计

本页保留旧稀疏设计的计算方式、实测指标及已有同模型浅层对照。
旧代码、旧模型及旧仿真/实现产物已从当前工作树清理。
历史版本为Git提交44301418c406c1138586a4269766216fa23cb266。
主要指标另存[机器可读对照](../results/sparse_comparison.json)。

## 旧稀疏数据流

![旧稀疏前端与深层共享核心](figures/sparse_dataflow.svg)

1. 400个单位事件按行排列，L1遇到事件就向受影响的3×3位置累加权重。
2. L1使用24路加法，每次更新3个位置、每位置8通道。
   3组覆盖9个卷积位置；每组先用1拍读取旧部分和，再用1拍相加写回，
   每事件更新合计6拍。
3. 三行局部部分和按行号及列号余数分为9组。每组43个地址、每地址8×40位，
   逻辑容量15,480字节。完成一行后池化、加常量、计算脉冲。
4. L1把非零计数打成包交给L2；L2忙时，L1保留待发结果并等待。
5. L2使用48路计数×权重运算，把非零包贡献累加到局部3×3支持域。
   9组累加存储，每组22×640位，逻辑容量15.47 KiB。
6. L2完成池化和脉冲后仍生成完整16×24×32特征图，片上占12 KiB；
   折叠常量可能在零输入位置引发脉冲，完整位置需要处理。
7. L3以后共享深层卷积阵列；L3电流缓存4.5 KiB，两步特征缓存共18 KiB；
   深层每组权重相邻执行两步，全连接与读出在末端完成。

## 同模型、同16输入的浅层对照

这项已有分析固定user17/seed2022模型及16个validation输入，
比较旧稀疏前端与独立的稠密L1、L2。参数装载不计入下表；
稠密层级数字不含顶层交接。

| 项目 | 旧稀疏 | 稠密层级计算 |
| --- | ---: | ---: |
| L1/L2前端计算时间 | 平均49,307.7拍 | L1 12,776＋L2 13,336＝26,112拍 |
| L1等待L2接收的时间 | 平均27,306.8拍，包含在前端总时间内 | 层完成后通过完整特征存储交接 |
| L1有效权重贡献 | 平均28,755次 | 含padding的1,769,472个乘加位置 |
| L2有效权重贡献 | 平均422,895次 | 含padding的3,538,944个乘加位置 |

样本0的旧稀疏L1用47,320拍，前端合计51,305拍；
持续接收输出时的独立L1为19,816拍。
稀疏减少了实际权重贡献数量，但这次映射的按包控制、部分和存取和层间等待占用较多时间。
稠密阵列每拍并行处理的计算位置多，因此完成时间更短。

## 论文使用

本篇以当前稠密四版本对照验证浅层无状态与计算复用的时间、存储和能量收益。
旧稀疏设计用于解释：有效操作数量降低，需要与并行度、部分和访问及层间交接一起设计。
稀疏优化留给后续期刊扩展；本仓库不再保留其运行代码和产物。
