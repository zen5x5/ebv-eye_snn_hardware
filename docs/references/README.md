# 硬件设计阅读资料

当前眼动硬件性能比较与来源见[文献比较](../related_work.md)。本目录保存已有的硬件参考全文，供写作时核对架构、方法和实验定义。

- 2025_Tan_DVS_Based_Gaze_Processor_TCSI.pdf：直接注视坐标处理芯片，本文的重要比较对象。
- 2023_Li_FireFly_TVLSI.pdf：同为XCZU3EG器件族的SNN计算阵列。
- 2023_Li_FireFly_v2_arXiv.pdf：时间步局部处理与权重复用。
- 2023_Modaresi_OpenSpike_ISCAS.pdf：状态、权重与激活存储组织。
- 2025_Windhager_Differential_Time_ISCAS.pdf、2024_Windhager_Differential_Time_AICAS.pdf：硬件架构图组织与时间编码。
- 2023_Bezugam_EMG_Loihi_ISCAS.pdf：已有作者前期稿，用于图示组织参考。

当前电路与结果统一以[设计](../design.md)和[四版本结果](../results.md)为准。
