## 1. 任务、输入数据与模型

### 要解决什么问题

EBV-Eye使用朝向眼睛的事件相机记录眼部运动。普通相机按固定帧率输出整张图，
事件相机只在像素亮度发生变化时输出事件；每个事件包含时间、行、列和ON/OFF
极性。本项目不先检测瞳孔再做几何映射，而是让SNN直接从一段眼部事件预测屏幕
上的连续注视坐标`(x, y)`。

项目包含两类眼动数据：Pursuit记录眼睛跟随连续移动目标，Saccade记录眼睛在
离散目标之间跳转并稳定注视。正式精度结果覆盖user4～27的24名用户、eye0，
每名用户分别训练一个模型。当前完整RTL以Pursuit user15 eye0最终模型作为
逐拍实现对象；同一套定点规则另在Pursuit和Saccade共48个最终模型上完成完整
test评估。

### 一个硬件输入是什么

每个样本不是固定时长的视频帧，而是连续取得的400个ROI事件。ROI大小为
`192×256`；事件坐标经过2×2 SumPool后，等价输入为两个极性通道的
`2×96×128`整数计数图。若同一位置出现多个事件，该位置计数可以大于1；
因此模型输入不是二值图。

```text
400个事件：(timestamp, polarity, row, column)
  -> 眼部ROI与2×2坐标缩减
  -> 等价的2×96×128 ON/OFF计数图
  -> 直接回归屏幕连续坐标(x, y)
```

Pursuit样本的监督值是窗口末事件时刻对应的屏幕目标坐标。硬件内部不需要保留
原始微秒时间戳，因为当前模型在400事件窗口内使用聚合计数；时间戳只用于软件
生成窗口和标签。硬件接口保留极性和池化后的空间坐标，并按行排序后送入稀疏
前端。

### SNN模型结构

模型由八个3×3卷积脉冲层、两个脉冲全连接层和一个连续读出层组成，共96,792
个参数。L1～L5后执行2×2 MaxPool，L6～L8保持`40×3×4`空间尺寸：

| 阶段 | 通道或维度 | 输出尺寸 | 时间状态 |
|---|---|---|---|
| 输入 | ON/OFF两个极性通道 | `2×96×128` | 同一完整400事件输入重复两步 |
| L1 | `2→8`卷积＋Pool＋LIF | `8×48×64` | 无跨步状态 |
| L2 | `8→16`卷积＋Pool＋LIF | `16×24×32` | 无跨步状态 |
| L3 | `16→24`卷积＋Pool＋LIF | `24×12×16` | 保留`t0→t1`膜状态 |
| L4 | `24→32`卷积＋Pool＋LIF | `32×6×8` | 保留`t0→t1`膜状态 |
| L5 | `32→40`卷积＋Pool＋LIF | `40×3×4` | 保留`t0→t1`膜状态 |
| L6～L8 | 三层`40→40`卷积＋LIF | `40×3×4` | 保留`t0→t1`膜状态 |
| H1、H2 | `480→60→12`脉冲全连接 | `60→12` | 保留`t0→t1`膜状态 |
| readout | `12→2`连续线性层 | `(x, y)` | 对两步H2脉冲取时间均值后读出 |

模型使用`T=2`：同一完整400事件表示在`t0`和`t1`各输入一次。L1/L2经过续训
后不保留跨步膜状态，所以两步输出相同并允许硬件只计算一次；L3到H2保留膜
状态，第二步可以利用第一步留下的神经元状态。神经元输出是非负整数
MultiSpike，而不是只能取0/1的单脉冲。

## 2. 最新版数据流：一个样本怎样从400个事件算到连续注视坐标

当前最终方案称为**浅层事件驱动＋深层逐层相邻执行双时间步**。它先利用
L1/L2的空间稀疏性，只处理真正出现的事件和脉冲包；从L3开始，空间位置已经
基本被全部触及，因此转入规则的共享计算核心。整个加速器只配置一个深层
288-DSP卷积核心，各层依次使用它；在每一层内部，把`t0`和`t1`放在一起计算，
使同一块权重只读取和装载一次。

### 第1步：接收400个排序事件

每个样本含400个ROI事件。原算法的2×2 SumPool在硬件入口表现为行、列坐标
各除以2；同一极性和位置上的重复事件仍逐个保留。现有RTL从已经按行排序的
`(polarity, row, column)`单位事件流开始计算。

这与先生成`2×96×128`整数计数图再做卷积完全等价：若某位置累计了`n`个
事件，硬件便在该地址把对应权重累加`n`次。

### 第2步：L1直接由事件驱动，不先扫描整张输入图

每到一个单位事件，L1便把对应的S16权重散射到3×3支持域和8个输出通道：

```text
1个事件
  -> 3×3卷积位置
  -> 8个输出通道
  -> 同一拍最多发射9×8=72次权重加法
```

因此L1使用72个LUT加法lane，不需要乘法器。S40部分和保存在三行、九bank
环形缓存中；一组输出行完成后立即执行2×2 MaxPool，不保存完整卷积feature
map。三seed validation中，L1每样本平均执行28,679.3次有效加法，随后只发出
平均2,554.4个非零U8脉冲包。

L1没有跨时间步膜状态，而且`t0/t1`接收同一组400事件，所以L1只计算一次，
其输出同时代表两个时间步的输入结果。

### 第3步：L2只处理L1发出的非零脉冲包

L2的输入是`(位置, 通道, U8 MultiSpike计数)`。计数`n`若展开为`n`次权重
加法，平均需要785.234k次操作；直接做一次`n×weight`只需要364.499k次有效
MAC。因此L2使用48个DSP lane，每拍处理3个卷积tap和16个输出通道。

L2同样使用三行、九bank的S40部分和环形缓存，并在行完成后依次执行：

```text
S40卷积部分和 -> 2×2 MaxPool -> 加一次折叠常量 -> S24钳位 -> 无状态LIF
```

BN缩放和阈值已经折叠进权重与逐通道常量。一个2×2池化窗的四个位置共享常量
`b'`，所以

```text
max_i(z_i + b') = max_i(z_i) + b'
```

硬件可以先Pool再加一次常量，结果逐值不变，并把这部分常量加法降为四分之一。
L2有少数通道会仅由该常量产生1或2个脉冲，因此卷积累加只由非零包触发，但
结束阶段仍遍历全部768个池化后位置，生成完整的`16×24×32` L2脉冲平面。

L2也没有跨时间步膜状态，因此这张完整平面只计算一次，同时作为L3两个时间步
的共同输入。

### 第4步：L3卷积电流只算一次，再连续完成两次LIF

L3开始保留膜状态。虽然L3在`t0`和`t1`的膜不同，但它在两个时间步接收的是
同一张L2脉冲平面，所以卷积电流完全相同。硬件按8个输出通道为一块：

```text
装入L3权重块
  -> 用共享288-DSP核心计算一次卷积电流
  -> 保存4.5 KiB的S24电流tile
  -> 用该电流执行LIF(t0)，写入t0膜和脉冲
  -> 直接复用同一电流执行LIF(t1)，读取t0膜并产生t1脉冲
```

这样不需要第二次L3卷积，也不需要原先13.5 KiB的L3整层电流缓存。

### 第5步：L4～L8在每层内部相邻计算`t0/t1`

从L4开始，两个时间步的输入脉冲已经可能不同，所以两次卷积都要执行。优化点
是权重在两个时间步之间不变。对于每个
`8个输出通道×4个输入通道×3×3`权重块，硬件按以下顺序工作：

```text
从片上BRAM读取一个256-bit权重beat并装入PE寄存器
  -> 扫描t0输入，累加到t0的S40部分和
  -> 不重新读取权重，紧接着扫描t1输入，累加到t1的S40部分和
  -> 完成该层LIF，t0膜直接留在引擎内供t1使用
  -> 再装入下一个权重块
```

L3～L8共用一个288-DSP卷积核心。L3、L4……L8仍按顺序执行，层与层之间没有
同时计算；当前样本与下一样本也没有重叠。这里的收益来自权重、部分和与膜状态
局部复用，而不是复制多套层级流水线。

### 第6步：H1/H2和readout产生连续`(x, y)`

H1和H2使用同一个16-DSP线性引擎。同一256-bit权重beat先服务`t0`，下一拍
继续服务`t1`，随后完成两步LIF。最后H2的两步脉冲进入2-DSP readout，输出
连续屏幕注视坐标`(x, y)`。

从算术格式看，整条链路统一为：

```text
S16权重
  -> S40运行部分和
  -> Pool与折叠常量
  -> S24完整电流
  -> S16膜状态
  -> U8 MultiSpike
  -> S16权重readout
  -> 连续(x, y)
```

权重常驻片上BRAM，运行时以256-bit beat装入当前PE的近端寄存器。控制器负责
层号、权重块、空间扫描、两个时间步、ready/valid握手和局部存储地址。

## 3. 为什么选择这条数据流

真实validation活动表明，L1和L2的非零位置比例分别只有10.4%和30.2%；其卷积
支持扩张并经过Pool后，仍分别有79.9%和57.1%的目标位置未被突触触及。L3以后
空间基本全部被触及，因此浅层适合事件路由，深层适合固定规则的DSP阵列。

L1/L2取消跨时间步状态还使两步结果能够复用。两任务正式模型的跨步状态由
45,000个元素降到8,136个，S16容量由87.89 KiB降到15.89 KiB。计入浅层
跨步复用后的完整test SynOps如下：

| 任务 | 全状态 | L1/L2无状态 | 减少 |
|---|---:|---:|---:|
| Pursuit | 10.810M | 7.298M | 32.50% |
| Saccade | 12.132M | 8.375M | 30.97% |

SynOps用于描述模型中由脉冲触发的权重累加。后面的硬件主比较采用RTL实际发射
的固定宽度lane slot，避免把算法操作数与硬件周期混为一个指标。

## 5. 三种完整硬件组织的同模型对照

为分开测量“浅层事件驱动”和“深层双时间步复用”各自的贡献，已经实现三套
L1～readout完整顶层：

1. **稠密扫描基线**：L1/L2也扫描整张feature map；深层先完成`t0`整网，
   再完成`t1`整网。
2. **仅浅层事件驱动**：L1/L2改为事件和非零脉冲包驱动；深层仍先完成`t0`
   整网，再完成`t1`整网。
3. **浅层事件驱动＋深层逐层相邻执行双时间步**：保留同一稀疏前端，L3以后
   在每层、每个权重块内相邻执行`t0/t1`。这是最终方案。

| 指标 | 稠密扫描基线 | 仅浅层事件驱动 | 浅层事件驱动＋深层逐层相邻执行双时间步 |
|---|---:|---:|---:|
| L1/L2执行方式 | 稠密空间扫描 | 事件与非零包驱动 | 事件与非零包驱动 |
| 深层执行顺序 | 先`t0`整网，再`t1`整网 | 先`t0`整网，再`t1`整网 | 每层、每个权重块内相邻`t0/t1` |
| scheduled lane slot/样本 | 14.592408M | 7.911147M | 7.911147M |
| 平均周期 | 83,286.0 | 72,444.9 | 67,942.9 |
| 逻辑activation读beat | 54,420 | 29,844 | 29,844 |
| activation写beat | 6,634 | 2,794 | 2,794 |
| 256-bit运行期权重读beat | 11,982 | 11,892 | 6,060 |
| 核心外部状态元素读/写 | 8,136 / 16,272 | 8,136 / 16,272 | 0 / 0 |
| 引擎局部状态元素读/写 | 0 / 0 | 0 / 0 | 8,136 / 8,136 |
| L3电流缓存容量 | 13.5 KiB整层 | 13.5 KiB整层 | 4.5 KiB局部tile |
| DSP48E2 | 306 | 354 | 354 |
| BRAM36等效 | 113 | 117 | 80.5 |
| FF | 34,048 | 36,941 | 36,124 |
| 200 MHz设计点时间 | 0.416 ms | 0.362 ms | 0.340 ms |
| 200 MHz设计点服务率 | 2,401.4/s | 2,760.7/s | 2,943.6/s |

最终方案相对稠密扫描基线取得：

- scheduled lane slot减少45.79%；
- 平均周期减少18.42%，核心服务速度提高到1.226倍；
- activation读、写分别减少45.16%和57.88%。

在已经采用浅层事件驱动之后，深层逐层相邻执行双时间步又取得：

- 运行期权重读取由11,892降到6,060 beat，减少49.04%；
- 平均周期再减少6.21%；
- BRAM36等效量由117降到80.5，减少31.20%；
- L3电流缓存由13.5 KiB整层缓存变为4.5 KiB局部tile。

scheduled lane slot表示固定宽度算术路径实际发射的工作，包括边界和通道tile中
被屏蔽的lane；它不等同于晶体管翻转次数或能量。

## 6. RTL正确性验证

三seed、426个validation样本的软件位精确稀疏回放共检查345,080,448个
L1～readout电流、膜、脉冲和输出值，失配为0。检查覆盖：

- L1事件散射和L2非零count-MAC；
- Pool后添加折叠常量以及L2默认脉冲平面；
- L3卷积电流只计算一次并供两个时间步复用；
- L4～L8和H1/H2的相邻双时间步执行；
- 最终连续`(x, y)`读出。

seed2022 validation样本0又分别通过三套完整顶层RTL。每套检查159,408个值，
失配和range error均为0；三套顶层实测周期分别为83,286、72,431和67,929拍。
两套事件驱动顶层均通过Icarus Verilog 13.0仿真和Verilator 5.052 `--Wall`。

完整validation的1,278个seed—样本周期统计由逐样本、逐周期的前端
ready/valid FSM回放，加整网RTL校准后的固定后端构成。平均值67,942.9拍反映
真实样本稀疏度分布；其中seed2022样本0完成了完整顶层逐拍RTL回放。

## 7. AUP-ZU3资源映射

目标器件为RealDigital AUP-ZU3上的`XCZU3EG-2SFVC784E`。最终方案的Yosys
整顶层映射如下：

| 资源 | 最终方案 | 器件容量 | 占用或判断 |
|---|---:|---:|---:|
| DSP48E2 | 354 | 360 | 98.3% |
| BRAM36等效 | 80.5 | 216 | 37.3% |
| FF | 36,124 | 141,120 | 25.6% |
| 物理LUT理论界 | 56,211～95,133 | 70,560 | 容量线位于上下界之间 |

354个DSP由L2的48个、共享深层卷积核心的288个、H1/H2的16个和readout的
2个组成。L1的72个加法lane使用LUT。当前结构的主要资源取舍是用掉98.3%的
DSP换取高并行度，同时通过深层时间局部性将BRAM36等效量控制在80.5。

LUT范围来自Yosys primitive与LUTRAM容量的打包上下界；它不能给出Vivado
布局布线后的实际LUT数。当前硬件阶段已经完成可综合RTL、功能仿真和开源
primitive mapping，没有布局布线后的Fmax、功率或板上测量值。

## 8. 与已有硬件工作的性能定位

### 端到端任务性能
