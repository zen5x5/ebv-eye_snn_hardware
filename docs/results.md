## 四组使用同一条复用规则

计算阵列、数值位宽、网络尺寸、权重加载接口和逐层连续处理两个时间步的顺序相同。
前面连续无状态的层计算一次；第一层有状态层复用相同的卷积/池化结果，
分别执行两次神经元运算，并在两步之间保存和读取膜电位；再后面的层完整计算两步。

| 模型 | 完整输出只算一次的层 | 卷积结果复用、神经元计算两步的层 |
| --- | --- | --- |
| 全有状态 | 无 | L1 |
| 仅L1无状态 | L1 | L2 |
| L1～L2无状态 | L1、L2 | L3 |
| L1～L3无状态 | L1、L2、L3 | L4 |

全有状态组两步输入也相同，所以L1的卷积可以复用，两个时间步的神经元状态照常更新。
四组都通过运行时接口加载权重，综合时没有将某个模型权重写成固定电路常量。
片上存储按各组所需的第二步特征、膜电位、分段累加结果和复用电流配置。
