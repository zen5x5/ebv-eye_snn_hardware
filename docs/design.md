# 当前四版本硬件设计

## 输入、网络和执行顺序

每个样本为400个事件聚合的2×96×128整数图。两个时间步重复这张完整图，
每个新样本开始时重置跨步状态。主设计采用L1/L2无状态，输出连续屏幕注视坐标。

| 层 | 通道或维度 | 每步输出 |
| --- | --- | --- |
| L1 | 2→8，3×3卷积、2×2最大池化 | 8×48×64 |
| L2 | 8→16，同上 | 16×24×32 |
| L3 | 16→24，同上 | 24×12×16 |
| L4 | 24→32，同上 | 32×6×8 |
| L5 | 32→40，同上 | 40×3×4 |
| L6～L8 | 每层40→40，3×3卷积 | 40×3×4 |
| H1、H2 | 480→60→12，脉冲全连接 | 60、12 |
| 读出 | H2两步取均值，再12→2线性层 | 连续x、y |

归一化和可学习阈值折叠进各通道权重与常量。权重/膜16位、电流24位、脉冲8位；
卷积运行部分和为40位，最终读出为64位整数及缩放设置。alpha固定0.75。

## 同一个核心支持四种状态深度

`pursuit_state_depth_timing_top`提供时钟与32位寄存器接口；
`STATELESS_DEPTH=0/1/2/3`选择全状态、仅L1、L1～L2或L1～L3无状态。
四种配置使用相同的8输出通道×4输入通道×9卷积位置阵列，权重在运行时加载。

| 深度 | 完整输出计算一次 | 卷积结果计算一次、神经元执行两步 |
| --- | --- | --- |
| 0 | 无 | L1 |
| 1 | L1 | L2 |
| 2，主设计 | L1、L2 | L3 |
| 3 | L1、L2、L3 | L4 |

前面的无状态层计算一次。第一层有状态层面对相同输入，先保存卷积/池化电流，
连续用于两步神经元运算；后续有状态层分别处理两步特征。
全状态基线同样复用L1卷积。

## 主设计一个样本的数据流

1. 主机把定点权重、各通道常量和小数位设置装入片上存储。
2. 把400事件计数图的24,576个值写入输入存储。
3. L1按固定空间顺序扫描输入，权重留在计算阵列附近，完成卷积、池化、阈值比较和发放；
   输出8×48×64个脉冲计数，保存为L2输入。
4. L2读取L1特征，以同一个共享卷积阵列完成计算，保存16×24×32个计数。
5. L3的卷积/池化结果按输出块缓存，先执行T1的膜更新和发放，
   再把衰减后的膜与同一卷积结果结合，得到T2输出；两步特征分别保存。
6. L4～L8按层执行，装入一组权重后相邻处理T1、T2，再切换下一组。
   膜电位、两步部分和及特征存储承担跨步保留。
7. H1/H2按同样的两步相邻顺序计算。两步H2脉冲相加，读出层形成两维结果。
8. 通过寄存器接口读出坐标整数及缩放设置。

各层共享计算阵列，前一层输出完成后再交接。稠密扫描的计算拍数固定，
L1没有等待L2消费逐个非零脉冲包的交接过程。

## 时间、资源和接口

主设计核心78,817拍，160 MHz下0.49260625 ms；输入写入为49,152条命令，
按每拍一条计算为0.3072 ms。权重初始化62,462条命令，可跨样本保留。
核心时间从输入和权重已经装入片上后开始计时。

布局布线后整体为29,546 LUT、17,113 FF、308 DSP和122块BRAM36等效。
这个统计包含寄存器评估接口。评估引脚约束用于器件实现与时序分析，
板级接线、时钟生成和上板测量留在期刊扩展中。

代码只保留这套参数化实现：
- `hardware/rtl/`：10份计算与接口模块，逐字保持已验证RTL。
- `tests/rtl/`：功能回放与布线后活动捕获两个测试台。
- `hardware/vivado/`：综合、布线、审计、功耗和活动记录脚本。

所有指标与源码校验信息在[原始总表](../results/summary.json)。
